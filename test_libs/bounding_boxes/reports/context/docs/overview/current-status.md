## Provisional decision



[Conclusions](../findings/conclusions.md) prefer **MinerU Basic as the segmentation base for this collection**, combining the user's visual preference, near equivalence to Standard in measured geometry and lower recorded resource use. This is a provisional technical choice. No complementary technique or validated ensemble has been implemented. It does not demonstrate the best true coverage, global semantic accuracy or universal hardware requirements.
