# Repository scope

This is a portable review snapshot, not a replacement for the canonical research workspace. Documentation and notebook explanations are translated into English. The snapshot manifest retains original source SHA-256 digests and separately records exported-file digests, so translated derivatives are not presented as byte-identical originals. Generated notebooks have outputs and execution counts cleared if present.

Source-language category values, validation markers, test fixtures, paths and identifiers are retained where they belong to existing data or runtime contracts. Historical manifests inside the demo describe its original source bundle; they do not certify the translated documentation. The unchanged `demo/src/` source snapshot preserves that bundle's code contract. Local audit backups are excluded from this distribution and remain in the original research workspace.

## Included

Integration modules, required supporting source packages, their tests and viewer templates, original parser adapters, selected analytical reports, architecture/contract, and Jupyter demo source and version locks. Synthetic fixtures are embedded in the unit tests. The demo `src/` duplicate is intentionally retained because its existing source-snapshot contract depends on those exact copies.

## External material

Paper PDFs, parser-output ZIPs, renders, crops, model weights, vendored dependencies, complete generated outputs, local execution logs and archived conversations are not included. Obtain authorized research inputs separately. A private GitHub repository does not itself establish permission to redistribute third-party papers.

## Historical documentation

Selected original reports and module guides retain references to the full research workspace. Relative links to results, history, plans or configuration absent from this snapshot are archival references and may not open here. They are not execution instructions or new authorizations. The root README provides the self-contained navigation for this distribution. Recorded local paths identify historical environments, not portable defaults.

GROBID remains deferred. Legacy retry scripts and remote launchers are retained only as source history/support; do not run them to inspect the repository. No services, model downloads or parser inference were started to prepare this snapshot.
